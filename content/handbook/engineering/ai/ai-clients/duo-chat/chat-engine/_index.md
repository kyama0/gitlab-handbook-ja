## 💻 範囲 {#-scope}

Chat Engine チームは、すべてのサーフェスで Duo Chat を支えるコアエンジンを担当します。

- Duo Chat の AI バックエンドと LLM 統合
- ツール統合とスラッシュコマンド
- すべてのホストシステムが使用するチャットプラットフォーム機能と API
- 信頼性、スケーラビリティ、オブザーバビリティに関する技術戦略

技術戦略の詳細については、[Duo Chat 技術戦略](/handbook/engineering/ai/duo-chat/technical-strategy/)を参照してください。
