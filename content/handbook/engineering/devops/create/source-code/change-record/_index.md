## 私たちの取り組み {#what-we-do}

Change Record は、コードのコミットとマージ後の変更追跡の流れに注力します。チームは、変更の記録と、その利用者への見せ方を担当します。

このページは書きかけです。担当範囲、責任、および働き方については、チームが定義するにつれて追加します。
