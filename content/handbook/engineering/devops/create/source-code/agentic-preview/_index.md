## 私たちの取り組み {#what-we-do}

Agentic Preview は、コミットに至るまでのユーザージャーニーを担当します。チームは、エージェントに関するメタデータを取得して処理し、その先に進む前に人が確認できるプレビューに変換します。

このページは書きかけです。担当範囲、責任、および働き方については、チームが定義するにつれて追加します。
