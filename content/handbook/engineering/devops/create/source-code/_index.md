Source Code Management グループを構成するエンジニアリングチームのページにアクセスするには、以下のリンクをご利用ください。

一時的に設置された [Source Code Hardening & Modernization チーム](/handbook/engineering/devops/create/source-code/hardening-and-modernization/)（2026-09-21 → 2027-09-10）は、Source Code 全体にわたる構造的なセキュリティとフロントエンドの問題に対処します。

常設の [Repository Services チーム](/handbook/engineering/devops/create/source-code/repository-services/)は、Source Code のリポジトリ領域を担当し、Gitaly チームの基本機能の上にアクセスレイヤーを構築します。
