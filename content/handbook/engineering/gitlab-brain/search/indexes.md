## 担当範囲 {#scope}

このチームは、GitLab のすべての検索インデックスを運用します。[Exact Code Search](https://docs.gitlab.com/user/search/exact_code_search/)の基盤となる Zoekt、[Advanced Search](https://docs.gitlab.com/user/search/advanced_search/)の基盤となる Elasticsearch、および両方を最新に保つインデックス作成パイプラインです。複雑なサブシステムを担当するチームとして、深い専門知識を持ち、対象範囲を絞っています。チームは SLO、鮮度、キャパシティ、コスト、およびアップグレードに責任を持ちます。その上位にある体験とランキングは、[Global Code Search Experience](experience/)が担当します。
