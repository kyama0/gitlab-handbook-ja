## ミッション

GitLab Secrets Manager プロダクトを構築および運用し、アップストリームに貢献します。

Application チームは、Rails インテグレーション、API、UI、シークレットを利用するための CI/CD エクスペリエンスという、GitLab 側のプロダクトサーフェスを担当します。

| --- | --- |
| Engineering Manager | Connor Fleming（`@cfleming3`） |
| Tech Lead | Erick Bajao（`@iamricecake`） |

現在のメンバー情報は Workday を情報源とし、[プロダクトカテゴリページ](/handbook/product/categories/#sec-section)で公開しています。

## 沿革

このチームは、FY27 の Sec 再編で旧 Pipeline Security グループを分割して設立され、そのラベル履歴を引き継いでいます。`group::pipeline security` は `group::secrets manager application` に名前が変更されたため、ラベル ID とそれに紐づくすべての Issue およびマージリクエストも引き継がれました。

共有グループページは、[Secrets Manager グループページ](/handbook/engineering/development/sec/security-platform/secrets-manager/)にあります。
