## ミッション

GitLab Secrets Manager プロダクトを構築および運用し、アップストリームに貢献します。

OpenBAO チームは、シークレットを保存および提供する [OpenBAO](https://openbao.org/) バックエンドを担当します。これには、GitLab における OpenBAO のデプロイとアップストリームプロジェクトへの貢献が含まれます。

## 沿革

このチームは、FY27 の Sec 再編で旧 Pipeline Security グループを分割して設立されました。`group::pipeline security` ラベルの履歴は [Application チーム](/handbook/engineering/development/sec/security-platform/secrets-manager/application/)に残ったため、OpenBAO のメトリクスは再編の切り替え時点から始まります。

共有グループページは、[Secrets Manager グループページ](/handbook/engineering/development/sec/security-platform/secrets-manager/)にあります。
