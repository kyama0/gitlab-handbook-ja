## 沿革

このグループは、FY27 の Sec 再編で設立されました。IAM リポジトリと OAuth Rails コードの変更を扱い、Authentication と Authorization の両方からメンバーが参加しています。意図的に Authorization のラベル履歴を継承していないため、メトリクスは再編の切り替え時点から始まります。

このページはスタブです。グループからの貢献を歓迎します。[ハンドブックの更新方法](/handbook/about/)を参照してください。
