## ミッション

セキュリティインベントリ、セキュリティ属性とプロジェクト分類、設定プロファイル、およびそれらを基盤とするエージェント型イネーブルメントワークフローを含め、GitLab のセキュリティ機能のイネーブルメントとプロダクト主導の成長を担当します。

## 沿革

このグループは、FY27 の Sec 再編で Security Platform Management から名称変更されました。`group::security platform management` ラベルは `group::security controls` に名前が変更されたため、ラベル ID とそれに紐づくすべての Issue およびマージリクエストが引き継がれ、メトリクスの履歴も保持されています。

このページはスタブです。グループからの貢献を歓迎します。[ハンドブックの更新方法](/handbook/about/)を参照してください。
