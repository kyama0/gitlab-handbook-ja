## 概要

チームメンバーは、個別の雇用契約または合意に含まれる相反する記載に従い、[GitLab 内部利用ポリシー](/handbook/people-group/acceptable-use-policy/)に沿って、ゲームや個人のブラウジングを含む限定的な個人利用のためにラップトップを使用できます（裁量によります）。これには、ソーシャルメディア、オンラインバンキング、通常の消費者向けアプリケーションが含まれます。業務用コンピューターを職場での閲覧に不適切（NSFW）な Web サイトに使用することは決して良い考えではありません。

私たちの懸念は通常、多数のポップアップ、クリックベイト、有名人の写真が複数ページにわたって含まれる Web サイト、またはマルウェアの影響を受けやすい Web サイトから始まります。言い換えると、Facebook のニュースフィードは閲覧できますが、広告を開かないようにしてください。マルウェアのインストールに対する脆弱性がはるかに低い個人用のスマートフォンまたはタブレットから、この種の Web サイトにアクセスしてください。

オンボーディング Issue の一部として、[GitLab 内部利用ポリシー](/handbook/people-group/acceptable-use-policy/)を読む必要があります。

コンピューターは [Jamf](/handbook/security/corporate/systems/jamf) (MDM) および [SentinelOne](/handbook/security/corporate/systems/sentinelone) (EDR) によって、**アクセスするすべての URL を含めて**監視されていることに注意してください。これは遡及的なセキュリティ調査にのみ使用され、皆さんの活動を積極的に監視するものではありません。言い換えると、「ビッグブラザー」型の監視アプローチではなく、コンピューターが侵害された場合に可能な限り多くのフォレンジック上の証跡データを持つためのものです。確認できるデータの詳細は、この[スライドデッキ](https://docs.google.com/presentation/d/1C2ufNXF28l0KTd5PPTkq1TjUWeWPI44VfwYbsvOzkns/edit)で確認できます。
