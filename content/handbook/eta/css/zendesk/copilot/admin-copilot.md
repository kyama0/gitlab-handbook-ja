## Admin Copilot とは

[Zendesk](https://support.zendesk.com/hc/en-us/articles/10013995711386-About-admin-copilot) によると:

> Admin Copilot は、Zendesk 管理者が運用を効率化し、環境を最適化できるように設計された、プロアクティブな AI アシスタントです。Admin Copilot を使用すると、問題が深刻化する前に潜在的な問題を見つけ、新しいワークフローの作成を支援し、設定全体の非効率性を解消して、時間を節約できます。
