## Copilot の文章作成とは

Copilot の文章作成は、文章強化に基づいてグループ化された、さまざまな Zendesk Copilot 機能です:

- コミュニケーションガイドライン
- 文章を改善

## 現在の設定

- Zendesk Global
  - サンドボックス:
    - [x] コミュニケーションガイドライン
    - [ ] 文章を改善
      - アクセスできるユーザー: すべてのグループ
  - 本番環境:
    - [x] コミュニケーションガイドライン
    - [ ] 文章を改善
      - アクセスできるユーザー: すべてのグループ
- Zendesk US Government
  - サンドボックス:
    - [x] コミュニケーションガイドライン
    - [x] 文章を改善

  - 本番環境:
    - [x] コミュニケーションガイドライン
