## Copilot の文章作成とは

Copilot の文章作成は、文章強化に基づいてグループ化された、さまざまな Zendesk Copilot 機能です：

- コミュニケーションガイドライン
- 文章を改善

## 現在の設定

- Zendesk Global
  - Sandbox:
    - [x] Communication guidelines
    - [ ] Enhance writing
      - Who has access: All groups
  - Production:
    - [x] Communication guidelines
    - [ ] Enhance writing
      - Who has access: All groups
- Zendesk US Government
  - Sandbox:
    - [x] Communication guidelines
    - [x] Enhance writing
      - Who has access: All groups
  - Production:
    - [x] Communication guidelines
    - [x] Enhance writing
      - Who has access: All groups
