## アクションフローとは

[Zendesk](https://support.zendesk.com/hc/en-us/articles/8855513857306)によると、次のとおりです。

> アクションフローは、定義されたイベントによってワークフローが開始またはトリガーされたときに、Zendesk と外部システムでアクションを実行する、ユーザー定義の自動ステップシーケンスです。アクションフローは、設定されたアクションフロートリガーイベントに応じて実行することも、エージェントが agent copilot の自動アシストを使用して開始することもできます。アクションフロー内のステップには、Zendesk のアクションだけでなく、外部システムで発生するアクションも含められます。

これは Zendesk で管理しているため、[Zendesk のドキュメント](https://support.zendesk.com/hc/en-us/articles/8855601898266)を参照してください。

これは Zendesk で管理しているため、[Zendesk のドキュメント](https://support.zendesk.com/hc/en-us/articles/9052312956570)を参照してください。

### アクションフローの削除

これは Zendesk で管理しているため、[Zendesk のドキュメント](https://support.zendesk.com/hc/en-us/articles/9052312956570-Editing-and-managing-action-flows#topic_chp_plv_bfc)を参照してください。
