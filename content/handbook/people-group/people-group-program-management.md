## 概要 {#overview}

People Group の Program Manager は、私たちの事業で最も影響の大きい目標と成果物について、認識の一致、測定、実行を推進します。効果的なプロジェクト管理を通じて、私たちの部門を整理し、計画どおりに進め、連携を保ちながら、俊敏性と部門横断的なコラボレーションを維持します。

## 主要なコンピテンシー {#key-competencies}

プログラムマネジメントという職務の中核で一貫性を維持するため、私たちの主要なコンピテンシーは、どのチームでも共通しています。職務ファミリーは GitLab 全体の役割の SSOT であり続けますが、People Group 内のすべての Program Manager に期待される主要なコンピテンシーと行動は以下のとおりです。

| 主要なコンピテンシー | 行動 |
| ------ | ------ |
| 専門領域に関する知見 | 機能領域内のプログラムをガイドする |
| 効果的なコミュニケーション | ステークホルダーへ定期的にプロジェクトの状況と可視性を提供する |
| 成長マインドセット | レトロスペクティブと最適化を通じて継続的改善を推進する |
| チェンジマネジメント | 方向転換とタイムライン調整を効果的に促進する |
| ステークホルダーマネジメント | チームを整合させ、成果物の実行に責任を持たせる |
| 戦略的計画 | 業務が部門および組織の全体的な目標と整合するようにする |
| プログラム方法論 | プロセスを文書化し、プロジェクト計画を管理し、リスクを軽減する |

*注意：会社全体のコンピテンシーは[こちら](/handbook/people-group/competencies/)、会社全体の職務フレームワークは[こちら](https://docs.google.com/spreadsheets/d/1FX4NBwF099uMBm7mGBtf1orIJZuHEjtiEa3jSbg9jJs/edit#gid=819074618)を参照できます。上記のコンピテンシーは、これらの既存の成果物を置き換えるのではなく、補完することを目的としています。*

### コラボレーションフレームワーク {#collaboration-framework}

複数の Program Manager が同じプロジェクトに取り組む場合は、

- DRI チームの Program Manager がエンドツーエンドの管理をリードします
- 他の Program Manager は、自身のチームの観点からパートナーシップを組みます
- 緊密なコラボレーションが統一的な実行を保証します
