## 概要 {#overview}

GitLab では、Microsoft Azure をサンドボックスとテストの目的にのみ使用します。
顧客のワークロードや開発のワークロードには使用しません。

## アクセスの申請 {#requesting-access}

Azure へのアクセスは、[Lumos](/handbook/security/corporate/systems/lumos/)を通じて申請します。
アクセス申請の作成方法については、[Lumos アクセス申請ガイド](/handbook/security/corporate/systems/lumos/ar/)を参照してください。

アクセス申請が承認されると、[Infrastructure Security（InfraSec）](/handbook/security/product-security/infrastructure-security/) チームが、必要なリソースグループやその他のリソースをプロビジョニングします。
