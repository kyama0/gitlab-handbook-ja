[Identity Engineering](/handbook/security/corporate/engineering/identity) が所有するアイデンティティおよびアクセス管理サービス — プロビジョニングのアーキテクチャ、自動化、セキュリティ管理。

リクエストおよび利用支援（アドホックなアクセスリクエスト、アカウントリセット、一時的なサービスプロバイダー、外部コラボレーター）は、[Corporate IT / End User Services](/handbook/eta/corporate-it/end-user-services/) が担当します。
